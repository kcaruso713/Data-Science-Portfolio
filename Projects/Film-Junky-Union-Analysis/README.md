# Film Junky Union Analysis

## Overview
Developed a machine learning model for the Film Junkie Union community to automatically classify IMDb movie reviews as positive or negative.

## Tool & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- TF-IDF
- Logistic Regression
- Natural Language Processing (NLP)

  ## Project Process
  - Cleaned and prepared movie review text for machine learning.
  - Explored review data and class distributions.
  - Converted text into numerical features using TF-IDF.
  - Trained and evaluated multiple text classification models.
  - Compared model performance using F1 score and ROC AUC.


  ## Results
  The Logistic Regression model achieved an **F1 score of approximately 0.89** and a **ROC AUC of approximately 0.96**, demonstrating performance in distinguishing positive from negative movie reviews.

  ## Key Skills Demonstrated
  Natural Language processing, text preprocessing, feature engineering, machine learning, model evaluation, and sentiment classification.
