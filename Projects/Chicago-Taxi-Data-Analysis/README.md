# Chicago Taxi Data Analysis

## Project Overview
Analyzed taxi trip data using SQL and Python to identify patterns in ride activity, taxi company performance, and popular drop-off locations.

## Objectives
- Examine and prepare taxi trip data for analysis.
- Identify the top taxi companies based on number of rides.
- Determine the top 10 neighborhoods by average number of drop-offs.
- Visualize transportation patterns to make key findings easier to interpret.

## Analysis
The project used SQL-based data collection and analysis along with Python for additional data exploration and visualization. Taxi companies were compared by ride volume, and neighborhood-level drop-off data was analyzed to identify the most frequently visited destinations.

## Visualizations
- Top taxi companies by number of rides
- Top 10 neighborhoods by average number of drop-offs
